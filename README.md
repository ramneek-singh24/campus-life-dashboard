# Campus Life Dashboard

> **Your Academic Hub. Stay Connected. Never Miss a Moment.**

A clean, responsive single-page dashboard designed for students to navigate campus activities, organize weekly timetables, manage tasks, and track announcements.

## 🚀 Key Features

1. **Personalized Welcome Overview**: Daily greeting with live summary stats for saved events and pending tasks.
2. **Campus Events**: Interactive list of upcoming workshops, hackathons, and fairs with bookmarking capability.
3. **Weekly Class Timetable**: Tabbed day-by-day view for class schedules, timings, and lecture hall locations.
4. **Notices & Announcements**: Dynamic feed featuring urgent updates, general announcements, and official notices.
5. **Campus Facilities Directory**: Real-time operating hours and open/closed status for library, health center, gym, and IT desk.
6. **To-Do List & Task Manager**: Interactive task list with local storage persistence to add, complete, and delete personal academic tasks.

## 🛠️ Step-by-Step Guide to Publish on GitHub Pages

Follow these simple steps to host this web application for free on GitHub Pages:

### Step 1: Create a GitHub Repository
1. Log in to your [GitHub Account](https://github.com/).
2. Click the **+** icon in the top right corner and select **New repository**.
3. Name your repository (e.g., `campus-life-dashboard`).
4. Set the visibility to **Public**.
5. Click **Create repository**.

### Step 2: Upload Project Files
1. Click the **uploading an existing file** link on your newly created repository page.
2. Drag and drop `index.html` (and `README.md`) into the GitHub upload area.
3. Scroll to the bottom and click **Commit changes**.

### Step 3: Enable GitHub Pages
1. In your repository, click the **Settings** tab at the top.
2. In the left navigation menu, click **Pages** (under *Code and automation*).
3. Under **Build and deployment** -> **Branch**, select `main` (or `master`) from the dropdown.
4. Leave the folder as `/ (root)` and click **Save**.
5. Wait 1 to 2 minutes. GitHub will provide your live website link:
   `https://<your-username>.github.io/campus-life-dashboard/`

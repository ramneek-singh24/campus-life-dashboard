# Campus Life Dashboard

> **Your Academic Hub. Stay Connected. Never Miss a Moment.**

A clean, responsive single-page dashboard designed for students to navigate campus activities, organize weekly timetables, manage tasks, and track announcements.

## 🚀 Key Features

1. **Personalized Welcome Overview**: Daily greeting with live summary stats for saved events and pending tasks.
2. **Campus Events**: Interactive list of upcoming workshops, hackathons, and fairs with bookmarking capability.
3. **Weekly Class Timetable**: Tabbed day-by-day view for class schedules, timings, and lecture hall locations.
4. **Notices & Announcements**: Dynamic feed featuring urgent updates, general announcements, and official notices.
5. **Campus Facilities Directory**: Real-time operating hours and open/closed status for library, health center, gym, and IT desk.
6. **To-Do List & Task Manager**: Interactive task list with local storage persistence to add, complete, and delete personal academic tasks.
